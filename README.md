# Simple Archiver

## Описание

Учебный проект по основам Go. CLI-приложение для архивирования и распаковки файлов с помощью RLE алгоритма. Интерфейс реализован с помощью Bubble Tea библиотеки.

## Установка и запуск

```bash
go run ./main.go
```

###

Главное меню
```bash
=== Простой архиватор ===

> Сжать файл
  Распаковать файл
  Выход

Используйте стрелки для навигации и enter для выбора
Нажмите q для выхода
```

Сжатие файла
```bash
=== Простой архиватор ===

Введите путь к файлу для сжатия:
pathToFile_

Enter для подтверждения, Esc для возврата в меню
```

Распаковка файла
```bash
=== Простой архиватор ===

Введите путь к файлу для распаковки:
pathToFile_

Enter для подтверждения, Esc для возврата в меню
```
